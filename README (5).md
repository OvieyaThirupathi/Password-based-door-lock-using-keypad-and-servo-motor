  
 **PASSWORD BASED DOOR LOCK USING KEYPAD AND SERVO MOTOR**

**1\. Aim**

To design a password-based door locking system using a keypad, Arduino and servo motor.

**2\. Problem Statement**

Traditional locks require physical keys, which can be lost or misplaced. A password-based system provides an alternative method for controlling access.

**3\. Proposed Solution**

A keypad is used to enter a password. When the correct password is entered, Arduino controls the servo motor to unlock the door. An incorrect password keeps the door locked.

**4\. Components Required**

Arduino UNO

4×4 Keypad

Servo Motor (SG90)

Breadboard

Jumper wires

Power supply

Door/lock model

**5\. Circuit Working**

The keypad receives the password entered by the user and sends the input to Arduino. Arduino compares the entered password with the stored password. If it matches, the servo motor rotates to unlock the door. Otherwise, the door remains locked.

**6\. Procedure**

1\. Connect the keypad to the Arduino.

2\. Connect the servo motor to the Arduino.

3\. Fix the servo motor to the door/lock mechanism.

4\. Upload the password-control program.

5\. Enter the password using the keypad.

6\. Observe the servo motor locking or unlocking the door.

**7\. Applications**

Home security

Locker systems

Office doors

Laboratory access

Small security systems

**8\. Advantages**

Keyless operation

Easy to use

Low-cost system

Simple to implement

Provides controlled access

**9\. Result**

The system successfully locks and unlocks the door using a password entered through the keypad.

**10\. Conclusion**

The project demonstrates a simple electronic security system where a keypad password controls a servo motor for locking and unlocking.

**11\. Project Demonstration**

The working model demonstrates password entry through the keypad and automatic movement of the servo motor for locking and unlocking.
